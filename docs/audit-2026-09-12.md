# Audit — 2026-09-12

Third full audit of the code, the repository and the running app, after the
Contemporary and True Divided Lite walkthroughs and the arrival of the complete
seven-page Dealer Wood Pricing sheet. Everything below was measured on the
branch at `8f0c53c` (PR #10), which is `main` plus the TDL work.

The two earlier audits are `audit-2026-09-09.md` and `audit-2026-09-10.md`;
this one says what has changed since, what is still open, and what was found
new. Each finding names how it was established.

## Verdict in one paragraph

The app is sound to quote with. Every price in the wood catalogue now matches
the vendor's own sheet cell for cell, or is explained; every card in every
collection reaches a price with no console errors; the pricing engine is a
single implementation cross-checked by a second one and by 4,308-cell
transcription tests; no secret has ever been committed; the Price Manager
round-trips the catalogue byte for byte. What is open is smaller than it was
and is listed honestly below. The one thing outside the code worth doing today
is protecting `main`, which is still unprotected.

**`main` is unprotected.** Nothing in the code path makes this dangerous today —
there is one collaborator and the README convention is never to push to `main`
directly — but a convention is not a control. The fix is one screen:
*Settings → Branches → Add branch protection rule → `main` → Require status
checks to pass → `test`*. With that, a red CI run physically cannot reach the
published site. It needs repository admin, which only the owner has.

The Price Manager's token handling was re-read: the PAT is held in
`sessionStorage` unless the operator ticks *remember*, sent only in an
`Authorization: Bearer` header to `api.github.com`, and the page says so in
plain words next to the box. No change recommended.

## 3. Pricing engine

Re-read adversarially. Nothing new.

- Money never leaves integers: list → cost is `roundCents(list × 0.48)`, cost →
  sell is `roundCents(cost / (1 − m))`, half-up. The only float in the file is
  a `1e-9` epsilon on the freight-unit ceiling, where a sidelite counts 0.5.
- `componentUpgrade` (PR #9) prices as the gap between two rows and never as a
  row of its own; a test asserts it never charges the whole casing.
- The second implementation (`tools/audit-prices.mjs`) still agrees on every
  one of its 13 checks; the 400-quote randomised stress test still agrees on
  every quote.
- 0.48 is now **vendor-confirmed**: it is printed in the sheet header.

**App A round-trips the catalogue byte for byte.** Established by loading the
real `catalog.json` through a mocked GitHub API and reading back what
`serializeCatalog()` would write: 531,788 bytes in, 531,788 identical bytes
out. The eight rule sections App A does not name (`glassRules`,
`sideliteRules`, `openingExtrasRules`, `trimProfileRules`, `dentilShelfRule`,
`woodStainColors`, `speakeasyOptions`, `skuPlaceholders`) all survive a save.
The array-shaped ones appear as generic grids; the object-shaped ones are
carried without a tab. Editing a rule in App A is possible but is a raw grid
with no guard rails — do it in the JSON with the audit running instead.

## 6. What is still open

In rough order of consequence.

1. **Protect `main`.** One screen, needs the owner. See §1.
2. **P.22 — 40 rows.** The next walkthrough. Flagged on every order until then.
3. **`KACM--3068-` / `-3080-`.** Two doors unsellable until the trailing
   character is identified. Parked for the knotty alder walkthrough.
4. **2880 casing and 1×4 trim.** No adder row for 2'8" doors (also 2668, 2680,
   2868). The door prehangs correctly; it cannot have trim added. The dealer
   passed on this twice; parked.
5. **Sidelites on the other 20 TDL models.** No catalog page shows one, so
   their behaviour was left as it was. Unknown, not wrong.
6. **Accessory count reads per door, bills per door × quantity.** Four clavos on
   a quantity-3 line charges twelve and shows "+ 4 ×". The money is right; the
   label should say "each". Unchanged from the last audit.
7. **24 silhouettes.** Photography, not correctness.
8. **Tell Hoelscher.** Their catalog prints fiberglass glass codes on the wood
   pages (17 numbers across pages 8–19); page 19 advertises six Craftsman 6
   Lite numbers the sheet prices two of; two captions contradict their own
   part number; `M6L--AT5080` names two doors on the sheet.
